# 拼多多数据挖掘

Windows 本机工具。按搜索词抓取拼多多商品，并可按关键词、禁用词、价格和标签筛选结果。

## 快速开始

需要 Windows 10 或 Windows 11，并保留系统自带的 Microsoft Edge。不需要安装 Python。
1. 解压整个程序文件夹。
2. 双击其中的程序exe。
3. 在界面中导入自己的登录信息(Cookie)，再开始搜索。
4. 最好是打开浏览器“新建无痕窗口”，登录拼多多网站，自己将cookie贴出来，否则限速的可能性会变大。

## 项目结构

- `app.py`：桌面程序入口。
- `pdd_search.py`：命令行入口。
- `pdd/browser/`：启动浏览器、保存登录状态、处理验证。
- `pdd/scraping/`：搜索、翻页、筛选和商品详情。
- `pdd/storage/`：按词条保存结果和分组。
- `pdd/services/`：登录、抓取任务和导出。
- `pdd/server/`：本机接口。
- `web/`：界面页面、样式和功能脚本。
- `icons/`：界面图标。
- `data/searches/`：按搜索词保存的商品结果。
- `tests/`：功能测试。
- `build/`：打包成程序的脚本。
